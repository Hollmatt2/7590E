## The app in one paragraph

A requester uploads a vendor contract. Saving it is all the website does; a separate program reads the file,
splits it into clauses, and looks for the provisions in Calder's playbook, by text rule or by asking Claude.
Each provision found becomes a "flag" holding the exact words that show it. A reviewer accepts, dismisses or
escalates every flag with a reason, then records the outcome for the whole agreement: cleared, cleared with
conditions, or escalated. Every decision is kept forever, and reports count what is waiting and what turns up
most often.

# config/settings.py — the project's settings

One file of values Django reads when it starts.

```python
DEV_SECRET_KEY = 'dev-only-not-a-secret'
SECRET_KEY = os.environ.get('DJANGO_SECRET_KEY', DEV_SECRET_KEY)
DEBUG = os.environ.get('DJANGO_DEBUG', '1') == '1'
```
`os.environ` is the set of settings the computer hands to the program when it starts, called environment
variables. `.get(name, fallback)` means "use this setting if it exists, otherwise use the fallback". So the
real secret key lives on the server, never in the code. The secret key is what Django uses to sign login
cookies: anyone who knows it can forge a login. Debug mode is on unless the setting says `0`.

```python
if not DEBUG and SECRET_KEY == DEV_SECRET_KEY:
    raise ImproperlyConfigured('Set DJANGO_SECRET_KEY before running with DEBUG off.')
```
**Bad input on purpose.** If someone deploys with debug off but forgets the key, the app refuses to start
rather than run in public with a key that is published on GitHub. This exact mistake happened on 2026-09-15
and is in the risk log.

```python
ALLOWED_HOSTS = os.environ.get('DJANGO_ALLOWED_HOSTS', 'localhost,127.0.0.1').split(',')
if os.environ.get('RAILWAY_PUBLIC_DOMAIN'):
    ALLOWED_HOSTS.append(os.environ['RAILWAY_PUBLIC_DOMAIN'])
```
A list of web addresses the app will answer to. Django rejects requests addressed to anything else, which
stops a class of attacks where someone sends a request pretending to be another site. Railway tells the app
its public address in `RAILWAY_PUBLIC_DOMAIN`, so it is added automatically.

```python
SESSION_COOKIE_SECURE = not DEBUG
CSRF_COOKIE_SECURE = not DEBUG
```
On the deployed site (debug off), the login cookies are only ever sent over an encrypted connection.

```python
DATABASES = {'default': dj_database_url.config(default=f'sqlite:///{BASE_DIR / "db.sqlite3"}', conn_max_age=600)}
```
On my laptop the database is a single file, `db.sqlite3`. On Railway, the setting `DATABASE_URL` points at
Postgres and this line uses that instead. `conn_max_age=600` keeps a database connection open for 10 minutes
instead of reconnecting on every page.

```python
MIDDLEWARE = [... 'whitenoise.middleware.WhiteNoiseMiddleware', ...]
STATIC_ROOT = BASE_DIR / 'staticfiles'
```
Middleware is a list of steps every request passes through. WhiteNoise serves the fixed files (the admin
screens' CSS), which Django does not do by itself when deployed.

```python
MEDIA_ROOT = Path(os.environ.get('MEDIA_ROOT', BASE_DIR / 'media'))
MAX_UPLOAD_MB = 20
AUTO_IDENTIFY = [method for method in os.environ.get('AUTO_IDENTIFY', 'rules,ai').split(',') if method]
AI_MODEL = os.environ.get('AI_MODEL', 'claude-haiku-4-5')
AI_LOW_CONFIDENCE = float(os.environ.get('AI_LOW_CONFIDENCE', '0.5'))
```
Where uploaded contracts are kept (on Railway, a storage volume at `/data/media`), the largest file the form
accepts, which automatic methods run, which Claude model, and the confidence below which an AI finding is
marked "low confidence".

**Why environment variables at all?** The brief (§9) requires that keys never enter the repository, and the
same code has to run on a laptop and on a public server without editing it.

# core/models.py — the database tables

Each class is one table; each attribute is one column. Django turns these into real tables through
"migrations", files in `core/migrations/` generated by a command, never written by hand.

```python
class User(AbstractUser):
    class Role(models.TextChoices):
        REQUESTER = "requester", "Requester"
        ...
    role = models.CharField(max_length=20, choices=Role, default=Role.REQUESTER)
```
Django's built-in user (username, password, login machinery) plus one column: the role. `TextChoices` is a
fixed list of allowed values: the left side is stored in the database, the right side is what people see.
**Bad input:** any other value fails Django's validation.

```python
class Severity(models.TextChoices):
    LOW = "low", "Low"; MEDIUM = ...; HIGH = ...
```
Written once outside the classes because both playbook entries and flags use it.

```python
class Provision(models.Model):
    name = models.CharField(max_length=100, unique=True)
    cuad_category = models.CharField(max_length=100, blank=True)
    definition = models.TextField(blank=True)
    default_severity = models.CharField(max_length=10, choices=Severity, default=Severity.MEDIUM)
    method = models.CharField(max_length=10, choices=Method, default=Method.AI)
    standard_position = models.TextField(blank=True)
    required = models.BooleanField(default=False)
```
One playbook entry: what Calder calls it, the matching CUAD label (used for measuring), what counts as this
provision, how serious it is, and whether a text rule or the AI looks for it. `unique=True` means two entries
cannot share a name. The last two fields are for the optional deviation and gap work that Change Notice 1
moved to stretch; nothing required uses them, and they are kept so that work has a place to go.

```python
class Agreement(models.Model):
    class Status(models.TextChoices):
        SUBMITTED = "submitted", "Submitted"
        PROCESSING = "processing", "Reading document"
        READ_FAILED = "read_failed", "Could not read document"
        AWAITING_IDENTIFICATION = "awaiting_id", "Waiting for identification"
        IN_REVIEW = "in_review", "In review"
        CLEARED / CLEARED_WITH_CONDITIONS / ESCALATED
```
The status is where the agreement is in the workflow. Everything in the app keys off it: which queue section
it appears in, whether the identification screen opens, whether the outcome form appears.

```python
    document = models.FileField(upload_to="agreements/")
    extracted_text = models.TextField(blank=True)
    read_error = models.TextField(blank=True)
    submitted_by = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.PROTECT, ...)
```
A `ForeignKey` is a link to a row in another table. `on_delete` says what happens if that row is deleted:
- `PROTECT` refuses the deletion. Used for the submitter, so history can never lose who submitted an agreement.
- `CASCADE` deletes the children too. Used for clauses and flags: delete an agreement and its clauses go with it.
- `SET_NULL` empties the link but keeps the row. Used for a flag's clause.

```python
class Clause(models.Model):
    position = models.PositiveIntegerField()
    class Meta: ordering = ["agreement", "position"]
```
One piece of the contract's text. `position` is 1 for the first clause. The `Meta` block means "whenever you
read clauses, hand them back in document order", so no page has to remember to sort them.

```python
class Flag(models.Model):
    kind = models.CharField(choices=Kind, default=Kind.PRESENT)
    severity = ...; source_text = models.TextField(blank=True); reason = models.TextField()
    confidence = models.FloatField(null=True, blank=True)
    source = models.CharField(choices=Source)     # rule / ai / manual
    status = models.CharField(choices=Status, default=Status.OPEN)
    created_by = models.ForeignKey(..., null=True, blank=True)
```
One finding. It always carries the exact words (`source_text`), why it was raised (`reason`), how serious, and
where it came from. `confidence` is empty for a person or a text rule, because neither produces a score.
`null=True` means the database may hold "nothing" there; `blank=True` means forms may leave it empty.

```python
    constraints = [models.CheckConstraint(
        condition=models.Q(confidence__isnull=True) | models.Q(confidence__gte=0, confidence__lte=1),
        name="flag_confidence_between_0_and_1")]
```
**Bad input.** The database itself refuses a confidence below 0 or above 1, even if some future code forgets
to check. A test proves it.

```python
    @property
    def is_low_confidence(self):
        return self.confidence is not None and self.confidence < settings.AI_LOW_CONFIDENCE
```
A `@property` is a value computed on demand that reads like a plain attribute. The review page uses it to mark
findings and to push them to the bottom.

```python
class FlagDecision(models.Model):
    flag = models.ForeignKey(Flag, on_delete=models.PROTECT, related_name="decisions")
    decided_by = ...; action = ...; reason = models.TextField(); decided_at = auto_now_add
class Disposition(models.Model):
    agreement = models.ForeignKey(Agreement, on_delete=models.PROTECT, related_name="dispositions")
    outcome = ...; conditions = ...; decided_at = auto_now_add
```
The audit record. Rows are only ever added, never edited: changing a decision writes a new row, and the newest
counts. `PROTECT` means a flag with decisions cannot be deleted, so the record cannot be quietly rewritten.
`auto_now_add` stamps the time on creation. `related_name` is the name used to read them back, as in
`flag.decisions.all()`.

# core/permissions.py — who may do what

```python
STAFF_ROLES = {User.Role.REVIEWER, User.Role.APPROVER, User.Role.ADMIN}
REVIEW_ROLES = {User.Role.REVIEWER, User.Role.APPROVER}

def can_view_agreement(user, agreement):
    return user.role in STAFF_ROLES or agreement.submitted_by_id == user.id
```
Staff roles see every agreement; everyone else sees only their own. `submitted_by_id` is the stored number of
the linked user, so this check needs no extra database read.

```python
def can_review(user, agreement):
    if agreement.submitted_by_id == user.id: return False
    if agreement.status == Agreement.Status.IN_REVIEW: return user.role in REVIEW_ROLES
    if agreement.status == Agreement.Status.ESCALATED: return user.role == User.Role.APPROVER
    return False
```
Three rules in one place: nobody reviews their own submission; reviewers and approvers handle agreements in
review; only the approver finishes an escalated one. Keeping them here rather than inside each page means
there is one place to check and one place to change.

```python
def role_required(*roles):
    def decorator(view):
        @login_required
        @wraps(view)
        def wrapper(request, *args, **kwargs):
            if request.user.role not in roles: raise PermissionDenied
            return view(request, *args, **kwargs)
        return wrapper
    return decorator
```
A decorator is a wrapper placed above a function with `@`. This one wraps a page so that visitors who are not
logged in go to the login page, and logged-in users with the wrong role get a 403 "Forbidden" page.

# core/forms.py — the forms and their checks

A form takes what someone typed, checks it, and either reports errors or hands back clean values. Methods
named `clean_<field>` check one field; `clean` checks the form as a whole.

```python
def squash(text):
    return " ".join(text.split())
```
Collapses every run of spaces and line breaks into one space, so text that wrapped across lines in a PDF can
still be compared with text someone pasted.

```python
class AgreementForm(forms.ModelForm):
    class Meta: model = Agreement; fields = [...]; widgets = {"needed_by": forms.DateInput(attrs={"type": "date"})}
```
A `ModelForm` builds its fields from the table, so the form and the database cannot drift apart. The widget
line makes the browser show a date picker.

```python
    def clean_needed_by(self):
        if needed_by < timezone.localdate(): raise forms.ValidationError("The needed-by date is already past.")
    def clean_document(self):
        ... extension not in {".pdf", ".txt"} -> error
        ... document.size > settings.MAX_UPLOAD_MB * 1024 * 1024 -> error
        first_bytes = document.read(5); document.seek(0)
        if not first_bytes.startswith(b"%PDF"): raise forms.ValidationError("That file is not a readable PDF.")
```
**Bad input, four kinds:** a date in the past, the wrong file type, a file over 20 MB, and a file that claims
to be a PDF but is not. Every real PDF begins with the characters `%PDF`, so a Word file renamed to `.pdf` is
caught here instead of crashing the reader later. `seek(0)` rewinds the file so the rest of the code can still
read it from the start.

```python
class FindingForm(forms.ModelForm):
    def __init__(self, *args, agreement, **kwargs):
        self.fields["clause"].queryset = agreement.clauses.all()
        self.fields["clause"].label_from_instance = lambda clause: f"Clause {clause.position}"
    def clean(self):
        if clause and text and squash(text) not in squash(clause.text):
            raise forms.ValidationError("That text does not appear in the chosen clause...")
```
The clause list is limited to this agreement's clauses, so nobody can attach a finding to another contract's
text. The check enforces the brief's rule (§5) that nothing may be shown that cannot be traced to real source
text. Spacing may differ; the words may not.

```python
class DecisionForm(forms.Form):
    action = forms.ChoiceField(choices=FlagDecision.Action.choices, widget=forms.RadioSelect)
    reason = forms.CharField(widget=forms.Textarea(attrs={"rows": 2}))
```
Accept, dismiss or escalate, and a reason. The reason has no `required=False`, so it is required: the record
must say why.

```python
class DispositionForm(forms.Form):
    def __init__(self, *args, outcomes, **kwargs):
        self.fields["outcome"].choices = [(o.value, o.label) for o in outcomes]
    def clean(self):
        if outcome == CLEARED_WITH_CONDITIONS and not conditions.strip():
            self.add_error("conditions", "Write the conditions the requester must meet.")
```
The outcomes offered are decided by the rules (see `core/review.py`) and passed in, so a forbidden outcome is
not even on the screen, and is rejected if someone sends it anyway.

# core/views.py — the pages

Each function takes a request and returns a page. The decorators above each one are the permission checks.

- `home` — the only page visible without logging in. Logged-in users are redirected: staff to the work queue,
  requesters to their submissions.
- `submit_agreement` — shows the intake form; on a valid submission saves the agreement, sets `submitted_by`
  to the person logged in, and **stops there**. Reading happens later, in a separate program. This is Change
  Notice 1's point: submission and analysis cannot live in the same request, or a large PDF would make the
  page hang.
- `my_submissions` — this user's agreements, newest first.
- `agreement_detail` — details, outcome, findings, history and clauses. It computes `show_findings`
  (`request.user.role in STAFF_ROLES`), so requesters see the status and outcome but not internal findings.
- `agreement_document` — sends the uploaded file, but only after the same permission check. Documents are
  never served directly by the web server, because the brief says they are not public (§3).
- `work_queue` — open agreements grouped by what they wait for, earliest needed-by first.
- `identify` / `remove_finding` / `finish_identification` — the manual identification screen: add a finding,
  undo one, and send the agreement to review. Removal is refused once review starts, because from then on the
  findings are part of the record.
- `review` / `render_review` / `decide_flag` / `add_missed_finding` / `dispose` — the review page, one
  decision, a finding identification missed, and the outcome.
- `reports` — the counts for Procurement.

Two pieces worth knowing by heart:

```python
def save_manual_finding(form, agreement, user, default_reason):
    flag = form.save(commit=False)
    flag.agreement = agreement; flag.kind = Flag.Kind.PRESENT; flag.source = Flag.Source.MANUAL
    flag.severity = flag.provision.default_severity
    flag.reason = flag.reason or default_reason
    flag.created_by = user
    flag.save()
```
`commit=False` builds the object without saving, so the fields the form does not collect can be filled in
first: severity comes from the playbook entry, the source is "a person", and the finding is attributed. Used
by both the identification screen and the review page, so the two cannot drift apart.

```python
    flags = sorted(flags, key=lambda flag: flag.is_low_confidence)
```
`sorted` with a key that is False or True puts False first, so low-confidence AI findings sit at the bottom of
the review page.

```python
    waiting.append({"stage": heading, "count": len(days),
                    "median": median(days) if days else None, "longest": max(days) if days else None})
    provisions = Provision.objects.annotate(found=Count("flags"), ...)
```
`annotate` asks the database to count related rows and hand back the number with each provision, instead of
looping in Python. **Bad input:** `median([])` would crash, so the code checks for an empty list first.

# core/templates/ — the pages' HTML

- `base.html` holds the header, the menu and all the styling; every other page starts with
  `{% extends "base.html" %}` and fills in `{% block content %}`.
- `{{ ... }}` prints a value; `{% ... %}` is an instruction such as `if` or `for`. Django escapes everything it
  prints, so contract text can never inject markup into the page.
- Logging out is a small form with a button, not a link, because it changes state and Django requires a POST.
- `core/templatetags/review_extras.py` adds the `highlight` filter, which marks the supporting words inside a
  clause on the review page. It escapes the text first, then inserts the `<mark>` tags, so highlighting cannot
  be used to smuggle HTML in.
