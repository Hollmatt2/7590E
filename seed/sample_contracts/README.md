# Sample contracts

Four contracts from CUAD, the Contract Understanding Atticus Dataset (v1), used as demonstration data by
`python manage.py seed_demo`. CUAD is published by The Atticus Project under the Creative Commons Attribution
4.0 license (CC BY 4.0): https://www.atticusprojectai.org/cuad. The contracts are public SEC filings; the files
are renamed but otherwise unchanged.
