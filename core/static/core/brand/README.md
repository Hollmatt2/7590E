# University of Georgia logo files

Official files from UGA's brand download center, "Institutional Logos", PNG raster section
(https://digitalarch.uga.edu/portals/q973imi3/Brand_Institutional_Logos), downloaded 2026-09-17.
They are used unchanged.

| File | Logo | Used on |
|---|---|---|
| `UGAlogo_ExtremeHoriz_FC_MARCM.png` | Extreme horizontal, full color (for light backgrounds), 2048 × 233 | Page header, on white |
| `UGAlogo_ExtremeHoriz_CW_MARCM.png` | Extreme horizontal, color white (for dark backgrounds), 600 × 68 | Page footer, on Arch Black |

Rules from the UGA Brand Style Guide (brand.uga.edu/visual-identity/logos/) that the site follows:
- Do not alter, distort, recolor, rotate, or add shadows or outlines to the logo.
- Clear space for the extreme horizontal logo: the height of the shield on every side.
- Full color on light backgrounds; color white on dark backgrounds.

The footer says the site is a student project and not an official University of Georgia service.
